## 2026-07-18 11:03 — 瑞幸 MCP 采用异步检测与商品白名单

- **选择**：固定官方 MCP 地址，仅允许门店与商品四项工具；定时命令负责握手检测，Dashboard 只读本地缓存，令牌仅从 `LUCKIN_MCP_TOKEN` 读取。

- **备选**：只在 Dashboard 展示能力说明，或另建一套 MCP 数据表和独立生成流程。
- **否决理由**：说明卡不构成接入；重复数据系统会绕开 GEOFlow 已有知识治理、切片、任务和证据链。

## 2026-07-18 12:03 — 官方快照保持不可变并迁入自有 fork

- **选择**：瑞幸 MCP 快照发布后禁止人工编辑，详情、重切片和删除采用资源级超管授权，通用素材 API 不允许修改或删除该快照；项目 `origin` 切到 `garetneda-gif/GEOFlow` fork，原 demo 仓库保留为 `demo` 远端。
- **备选**：允许超管直接改写官方快照，或继续把开发分支只推到独立 demo 仓库。
- **否决理由**：直接改写会绕过字段投影并继续携带官方来源标识；自有 fork 能保留与上游的父子关系，同时承载本项目分支和页脚链接。

## 2026-07-18 14:52 — 使用 Vercel PHP 与 Supabase 承载生产演示

- **选择**：Vercel 使用 `vercel-php@0.7.4` 运行 Laravel，Supabase 免费项目提供 PostgreSQL；业务表放入 `luckin_geoflow` schema，Serverless 请求使用 6543 连接池。
- **备选**：改写为 Node 前后端、继续使用 SQLite，或租用常驻 PHP 主机。
- **否决理由**：重写会偏离现有 GEOFlow；SQLite 与 Vercel 只读文件系统不适合生产写入；常驻主机会增加本次演示部署成本。

## 2026-07-18 14:52 — 通过显式代理信任保持生产 HTTPS

- **选择**：仅在设置 `TRUSTED_PROXIES` 时启用 Laravel 代理信任，Vercel 生产环境设为 `*`。
- **备选**：全环境无条件信任所有代理，或强制所有 URL 使用 `APP_URL`。
- **否决理由**：条件启用既能正确处理 Vercel 的转发协议头，也不会扩大本地和其他直连部署的信任边界。

## 2026-07-18 15:43 — 页头按字标而非图片盒子做光学对齐

- **备选**：让 Logo 图片盒子与导航行盒机械居中，或继续使用 `translateY(-2px)`。

## 2026-07-18 16:01 — 保留 6543 事务池但禁用命名 prepared statements

- **选择**：继续使用 Supabase 为 Serverless 推荐的 6543 transaction pooler，通过 `PDO::PGSQL_ATTR_DISABLE_PREPARES` 单次发送查询和参数。
- **备选**：切换 5432 session pooler，或开启 `PDO::ATTR_EMULATE_PREPARES`。
- **否决理由**：session pooler 并发容量更低；PDO 模拟预处理会把 Laravel boolean 绑定展开成整数，已在生产触发 `boolean = integer`。

## 2026-07-18 16:28 — 瑞幸 MCP 凭据改为管理员独立配置

- **选择**：超级管理员在 MCP 工作台自行粘贴官方 API Key，使用 Laravel Encrypter 加密后存入该管理员记录；页面只显示掩码，保存与清除请求全部审计脱敏。
- **备选**：继续使用全站统一 `LUCKIN_MCP_TOKEN`，或把密文按管理员数字 ID 存入通用设置表。
- **否决理由**：全站变量无法支持用户自行授权；通用设置表会在管理员删除且 ID 复用时留下凭据继承风险，凭据随管理员记录保存可自然消除该风险。

## 2026-07-18 20:26 — 腾讯云采用单机生产 Compose

- **选择**：在腾讯云轻量服务器以项目原生生产 Compose 运行完整常驻栈，公网只开放 Nginx 80，数据服务仅留在容器网络。
- **备选**：继续仅使用 Vercel/Supabase，或在宿主机分别安装 PHP、Nginx、PostgreSQL 与 Redis。
- **否决理由**：Vercel 在大陆存在连接边界；宿主机散装服务更难保证版本一致、自启、隔离和可重复部署。

## 2026-07-18 20:26 — IP 阶段先使用 HTTP

## 2026-07-18 20:59 — 演示环境显式展示管理员密码

- **选择**：新增默认关闭的 `GEOFLOW_LOGIN_DEMO_PASSWORD_ENABLED`；仅当环境密码与启用中的管理员账号哈希一致时，登录页才显示该密码。
